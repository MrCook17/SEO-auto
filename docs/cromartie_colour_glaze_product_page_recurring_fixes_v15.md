# Cromartie Colour & Glaze Product Page Recurring Fixes

Use this checklist when creating, editing or reviewing individual Cromartie Colour & Glaze product pages. It is designed for product-page SEO metadata, image SEO and CMS product description snippets.

Use alongside:

- `cromartie_colour_glaze_product_page_seo_guidance_workbook.xlsx`
- `cromartie_colour_glaze_product_page_seo_strategy_workbook_aligned.md`
- `cromartie_flexible_cms_styling_guidance_updated.md`
- `cromartie_colour_glaze_cms_style_guide.md`, only where the product page needs richer CMS styling

This file is product-specific. Do not use it as the main checklist for department, category, parent range or support/advice pages.

---

## 1. Product-page SEO role

- Product pages should stay exact-product focused.
- Use the product name, colour, brand, range, type, size, format and SKU only where useful.
- For colour-variant products, prefer colour-first naming where possible so product lists and metadata are easier to scan.
- When working through a department or range with many colour variants, use the preferred product-name recommendation pattern `{colour} - {whatever else} {quantity}` where the supplied facts support it.
  - Use this hyphenated pattern only for the `PRODUCT_NAME_RECOMMENDATION` field.
  - Do not automatically copy the hyphenated product-name pattern into meta titles, meta descriptions, CMS headings, CMS body copy, image title text, image alt text, link titles, anchor text, notes or any other output.
  - Put the colour first in the recommended product name.
  - Use a hyphen after the colour only inside the recommended product name.
  - Put the brand, range, product type or effect after the hyphen.
  - Put the verified size/quantity at the end.
  - Example product-name recommendation: `Bronze Patina - Duncan Metallic Glaze 118ml`.
  - Everywhere else, write naturally. For example, use `Polar Bear Gare Fun Strokes Underglaze is...` in body copy rather than forcing `Polar Bear - Gare Fun Strokes Underglaze is...`.
- Do not make product pages compete with parent departments, category pages or range pages.
- Broad terms such as `ceramic glazes`, `pottery glazes`, `underglazes`, `clear glaze for pottery`, `stoneware glazes`, `raku glazes`, `powdered glazes`, `non fired ceramic paint`, `pottery paints` or `ceramic sealer` usually belong to department/category/range pages, not individual product pages.
- Follow the product-page guidance workbook row before choosing the target keyword, meta title, meta description, image title or alt text.

## 2. Product metadata fixes

- Do not include product codes, SKUs or item codes in meta titles by default.
  - Most customers do not search Google by product code.
  - Use the product name, range/type, size, format, colour or use case instead.
  - Include a product code only if the user specifically asks for it or there is strong evidence that customers search by that code.
- Do not include product codes, SKUs or item codes in meta descriptions or CMS product descriptions by default.
  - The CMS/product template already displays the product code on the page.
  - Repeating it in the description usually adds clutter without improving the customer copy.
  - Include it only if the user specifically asks for it or the product code is genuinely needed for identification.
- For colour-variant products, put the colour first where it helps the customer scan and understand the item.
  - This makes similar products easier to scan in CMS exports, metadata batches and customer-facing lists.
  - Avoid making every similar product start with the brand, such as `Duncan Yellow...`, `Duncan Orange...` or `Duncan Red...`, unless the official product name or range convention genuinely requires it.
  - For departments or ranges with lots of colours, use the clearer product-name recommendation pattern `[Colour] - [Brand/Range/Product Type] [Size]` only in the product name recommendation.
  - Do not treat the product-name recommendation pattern as a required formula for meta titles, meta descriptions, target wording, CMS copy, image title text or image alt text.
  - Meta titles should be natural and product-led. They may start with the colour where useful, but they do not need the hyphenated product-name format.
  - Image title text and alt text should describe the actual image naturally, with no forced hyphenated product-name formula.
- Do not append `Cromartie` to meta titles if the CMS already adds the brand/site name automatically.
- Keep meta titles under 60 characters where possible.
- Keep meta descriptions under 160 characters where possible.
- Meta titles should be product-led, not broad-category-led.
- Meta descriptions should describe the specific product, not the whole department or range.
- Do not repeat the same meta description structure across many colour variants. Vary wording naturally while keeping facts accurate.

### Meta description variety rules

Meta descriptions should not feel copied across a full range of fired colour products. Each description should choose one main angle from the verified product facts and make that product feel worth clicking. This is especially important when processing many colour variants from the same department, where repeating the same formula quickly makes the output look automated.

- Avoid starting every description with `Shop`. Vary openings with natural verbs such as `Add`, `Create`, `Choose`, `Use`, `Explore`, `Discover`, `Find` or `Build your palette with`.
- Start with the colour, effect, use or product type when it creates a stronger description.
- Use one main value angle per product, such as:
  - colour tone
  - fired effect
  - finish, such as gloss, matt, satin, speckled, transparent, opaque or reactive, only when verified
  - application method, such as brush-on, dipping, spraying, sponging or powder, only when verified
  - firing range or cone range, only when supplied
  - surface suitability, such as bisque, greenware, earthenware or stoneware, only when supplied
  - decorating purpose, such as detail work, layering, background colour, test tiles or pottery painting, only where supported
  - why a maker would choose this fired colour instead of a non-fired decorative finish
- Vary the search intent wording only where it fits the exact product type. Useful options may include `fired ceramic colour`, `pottery colour`, `ceramic decorating colour`, `underglaze colour`, `ceramic glaze colour`, `kiln-fired colour`, `fired decoration for ceramics` or `colour for pottery painting`.
- Do not keyword-stuff by listing many near-duplicate terms in one description.
- Include a reason to click, such as controlled brushwork, colour testing, building a fired palette, adding surface interest or creating kiln-fired decoration, but keep the claim modest and supported.
- Keep descriptions natural and useful within normal meta description length.
- Do not invent firing ranges, food-safe claims, finish claims, application methods, suitability or compatibility.
- Include a clear exact-product identifier naturally, usually the colour plus the range or product type. A varied description should still make it obvious which individual product the result belongs to.
- Include the size only when it helps distinguish the variant or supports the buying decision. Do not force the size into every description when it makes the wording mechanical.
- Avoid generic subjective filler such as `perfect`, `ideal`, `versatile`, `premium`, `professional-quality`, `stunning`, `must-have`, `easy to use`, `reliable`, `vibrant` or `rich` unless that wording is directly supported by supplied facts or the visible fired result.
- Do not add unsupported commercial claims such as current stock, low stock, price, offers, fast delivery, availability, popularity or `best-selling`.
- Aim for roughly 140–155 characters where practical and stay under 160 characters where possible, but prioritise a natural complete sentence over forcing an exact count. Do not end with a cut-off phrase or unfinished thought.
- Use no more than one clear CTA or action-led opening in a meta description. Avoid stacking commands such as `Shop`, `discover`, `explore` and `buy` in the same sentence.
- Avoid repeating formulaic meta description patterns across adjacent colour variants, such as `[Colour] [Range] [Product Type] [Size] for bisque painting and ceramic decorating. Use 1 coat translucent or 2–3 coats opaque.` Use that structure only rarely if it is genuinely the clearest option.
- When several products share the same range instructions, vary the emphasis from product to product rather than repeating the same sentence with only the colour changed. Choose one supported angle, such as colour role, decorating use, buildable coverage, clear-glaze-before-firing workflow, testing before important pieces, palette building, detail work or studio/classroom use.
- Do not try to include every supplied fact in the meta description. The full application and firing details can go in the CMS snippet and specification table.
- Use varied but accurate CTA language, such as `Add`, `Create`, `Choose`, `Use`, `Explore`, `Discover`, `Find` or `Build your palette with`, where it reads naturally.
- After creating several products from the same range, compare adjacent meta descriptions. Rewrite any pair that shares substantially the same opening, sentence structure, value phrase and ending, even when the colour names are different.

#### Safe meta description angle patterns

Replace bracketed wording with verified product facts. These are angle patterns, not fixed templates to repeat across a range.

Colour-led:

```text
Add [verified colour tone] fired colour to pottery with [product/range], suited to [verified decorating use or application].
```

Use-led:

```text
Create [verified decorating outcome] with [colour and product type], using the supplied [application, surface or firing detail].
```

Comparison-led:

```text
Choose [colour and fired product type] for kiln-fired ceramic decoration rather than a temporary non-fired finish.
```

Range-led:

```text
Build a fired colour palette with [colour and range], suited to [verified pottery, studio, classroom or decorating context].
```

Effect-led:

```text
Add [verified finish or effect] to ceramic pieces with [colour and product type] for [verified surface or firing context].
```

## 3. Product H1 and H2 rules

- The CMS/product template usually outputs the product name as the page H1.
- Do not repeat the exact product name in the CMS HTML `<h2>` when the H1 already uses it.
- Use the `<h2>` to expand on the product's purpose, use case, format or buyer intent.
- Keep the H2 useful and customer-facing.
- Do not make the H2 a forced SEO phrase.

```html
<h2>Cadence Brush Cleaning Gel 120ml</h2>
```

## 4. First paragraph product-name repetition

- Mention the product name naturally in the first paragraph.
- The `{colour} - {whatever else} {quantity}` pattern is for the product name recommendation only, not a rule for the first sentence of the CMS snippet.
- If the recommended product name uses a hyphen, remove or rephrase the hyphenated format in body copy so the opening sentence reads naturally.
- Do not copy the hyphenated product name into the H2, meta description, link text, image title or image alt text unless it genuinely reads like the best natural wording for that field.
- Avoid repeating the size in the first sentence if it already appears in the product name/H1 and makes the copy read awkwardly.
- Do not force the full product name into every paragraph.
- After the first natural mention, use shorter wording such as `this brush cleaning gel`, `this clear glaze`, `this underglaze`, `this acrylic paint`, `this sealer` or `this product`, depending on context.
- Keep the first paragraph clear, useful and readable before trying to add keywords.
- The first sentence inside the first `<p>` tag must be easy for a human to read before it tries to carry SEO value. Do not overload it with colour, brand, range, surface, finish, use cases and firing context all at once.
- The opening sentence should usually do one clear job: introduce the product and explain the simple customer benefit. Move extra details such as use cases, decoration ideas, firing guidance or range context into the next sentence or paragraph.
- Avoid long stacked noun phrases such as `Pink Ribbon Gare Surface Coat gives clean bisque a soft light pink fired background with a gloss surface, ready for ceramic decoration, pottery painting and painted bisque designs.`
- Prefer a smoother opening such as `Pink Ribbon Gare Surface Coat is a soft light pink gloss glaze for adding a fired background colour to clean bisque.` Then use the next sentence for examples such as plates, ornaments, pottery painting or decorative pieces where supported.
- Read the first sentence back on its own before finalising. If it feels awkward, split it into two shorter sentences and keep the SEO phrase natural rather than forced.

### Example correction

Avoid:

```text
Keep brushes ready with Cadence Brush Cleaning Gel 120ml. This brush cleaning gel 120ml is...
```

Better:

```text
Keep brushes and creative tools ready for their next colour session with Cadence Brush Cleaning Gel. This handy brush cleaning gel is designed for cleaning up after painting...
```

## 5. Product bullet list rules

- Use the `<ul>` for useful factual product details only.
- Do not repeat the full product name in the bullet list unless it adds real customer value.
- Use bullets for facts such as:
  - size, volume or weight
  - colour
  - finish or effect, only when confirmed
  - range or product type
  - format, such as bottle, tub, powder, brush-on, dipping or spray
  - firing range or cone range, only when confirmed
  - application notes, only when confirmed
  - compatibility or suitability notes, only when confirmed
  - set contents or pack quantity
  - care, cleaning or safety instructions
- Keep bullets short and scannable.
- Do not use bullets to repeat claims already made clearly in the paragraphs.

### Example correction

Avoid when the product name is already obvious:

```html
<li>120ml bottle of Cadence Brush Cleaning Gel</li>
```

## 6. Product description copy rules

- Write confidently and directly when the product facts are supplied.
- Avoid uncertain phrases such as:
  - `the supplied product information states`
  - `according to the supplied product information`
  - `it appears to`
  - `may include`, unless availability genuinely varies
- Do not invent product facts, firing temperatures, food safety, dinnerware suitability, finish, effect, application method or compatibility.
- Do not over-explain simple products.
- Do not add the product code/SKU into the body copy unless there is a clear customer reason, because the CMS already displays it on the product page.
- Keep the main narrative description to exactly two substantial `<p>` tags. Move routine technical facts into the product specification table, and use a short `<ul>` only when it adds practical guidance that is not already covered by the paragraphs or table.
- Avoid unnecessary panels, feature boxes and `Why Choose` sections on simple product pages.
- Use notes only when the note helps the customer, such as image variation, safety, stock/pack variation or important usage guidance.
- Keep internal SEO logic out of customer-facing copy. Do not mention `keyword ownership`, `search intent`, `cannibalisation`, `this page owns` or similar.

### Two-paragraph main-description rule

For glaze product-page CMS snippets, write exactly two focused `<p>` tags for the main description. As a recommended guide, aim for roughly 45–70 words per paragraph, or around 90–140 words in total. This is not a strict limit and does not need to be counted or verified; it is completely acceptable to go over when the product needs more useful explanation.

**Paragraph 1: appearance and creative use**

- Describe the verified fired colour, finish and surface character.
- Explain where the result works best creatively, such as suitable pottery forms, textures, relief details or decorative styles, but only where supported by the supplied facts or visible fired sample.
- Help the customer picture the finished result without generic creative filler or unsupported guarantees.

**Paragraph 2: why choose it and essential guidance**

- Explain why a maker might choose the product over the nearest relevant glaze type, finish or decorating alternative.
- Follow this with one essential application, firing or variation note needed to make a sound choice.
- Leave mixing ratios, firing temperatures, coat counts, size, format and safety information in the specification table rather than repeating routine technical facts in the paragraphs.

Additional rules:

- Write exactly two `<p>` tags in the complete CMS snippet, not merely two before adding several more paragraphs later.
- Do not create a third paragraph for a colour note, link, CTA, safety reminder or repeated application guidance.
- Treat the suggested paragraph and total word ranges as writing guidance only. Do not count or verify the words, and do not shorten useful copy unnaturally just to fit the recommendation.
- Use a short `<ul>` only where it adds genuinely useful practical guidance and does not duplicate either paragraph or the specification table.
- Put verified structured facts in the purple Cromartie product specification table.
- Use CTA buttons or standalone inlink boxes for links after the specification table rather than extra paragraph text.
- Where an important warning or note genuinely needs separate treatment, use a concise styled `<div>` rather than adding another `<p>` tag.
- Do not invent appearance, compatibility, food-safety, performance, layering results, guaranteed fired colours, surface effects or comparison claims.

### Example: Alligator Matt

```html
<p>Alligator Matt produces a mottled metallic surface with silvery grey, muted green and darker areas, giving finished pottery an aged and organic character. Its broken surface effect works especially well on sculptural forms, textured vessels and relief decoration where the changing tones can emphasise shape and detail.</p>

<p>Choose this glaze when you want a weathered metallic result rather than the uniform coverage of a conventional gloss glaze or the defined pattern of a crackle glaze. Test the mixed consistency and application thickness before using it on important work, as the colour and surface response will naturally vary between Raku firings.</p>
```

### Revised reusable instruction

> Write exactly two `<p>` tags, normally 90–140 words in total. The first paragraph should describe the verified fired colour, finish and surface behaviour, then suggest suitable pottery forms, textures or decorative styles. The second should explain why someone would choose this glaze over the nearest relevant alternative and include one important application, firing or variation note. Do not repeat routine technical facts already included in the specification table, and do not invent appearance, compatibility, food-safety or performance claims. The word range is a recommendation only and does not need to be counted or verified; it is fine to go over when useful.

### Product description variety rules for repeated colour ranges

When working through a department or range with many similar fired colour products, avoid making every CMS snippet read like the same template with a different colour name. Keep the shared technical facts accurate, but vary the customer-facing angle and sentence structure from time to time.

- Do not repeat the exact same first paragraph across adjacent colour variants, such as `[Colour] [Range] is a [colour] underglaze colour for bisque painting, ceramic decorating and kiln-fired pottery colour work.`
- Do not repeat the exact same second paragraph, bullet list and CTA framing for every product in a colour-heavy range unless the product facts leave no other natural option.
- Use one clear product-specific or use-specific angle per description, such as:
  - colour tone or visual role, such as bright, soft, deep, earthy, white, black, green or warm, only where visible or supplied
  - fired effect or finish, such as gloss, matt, satin, speckled, reactive, opaque or transparent, only when verified
  - application method or workflow, such as brush-on, bisque application, clear glaze before firing or coat build-up, only when supplied
  - decorating purpose, such as detail work, background colour, pottery painting, colour testing, layering or building a fired palette, only where supported
  - studio, classroom or hobby use, only when the product facts support that broad use context
  - firing or surface requirements, such as Cone 04 bisque or Cone 06 firing, only when supplied
- Rotate paragraph openings naturally. Examples include `Use [product] for...`, `[Product] adds...`, `For makers needing...`, `This [type] is suited to...`, `Build...`, `Create...`, `Add...`, or `Choose...`. Do not overuse any one opening across a batch.
- Use the specification table to carry repeated technical facts. This lets the paragraphs focus on what the customer can do with the product rather than repeating the same instructions in every sentence.
- Keep the copy human and useful. Do not add variety by inventing facts, exaggerating performance or adding unsupported use cases.
- If several products in a row use the same range instructions, vary the bullets as well: some can focus on testing, some on coat build-up, some on clear glaze workflow, some on palette building, some on detail or background colour, where supported.

## 6A. Fired colour HTML snippet quality rules

Fired colour product descriptions should feel useful, enjoyable and practical rather than dry. They still need to stay exact-product focused and fact-led, but they should help the customer understand why the product matters and how it fits into ceramic work.

Use these points where supported by the product facts, workbook row, supplied notes or visible product context:

- Explain what the product is for: adding colour, decoration, detail, surface interest, background colour, layered effects or fired design work to ceramic pieces.
- Include suitable use cases where supported, such as pottery painting, ceramic decoration, studio ceramics, hobby ceramics, classroom work, test tiles, decorative pieces or functional ware.
- Explain why a maker might choose this type of fired colour: it is designed for kiln-fired ceramic surfaces, creates fired decoration rather than a temporary non-fired finish, or becomes part of the finished ceramic surface after firing.
- Mention surface or application compatibility only when verified, such as bisque, greenware, underglaze-style decoration, glaze layering, brush application, dipping, spraying, sponging or detail work.
- Describe the finish and visual effect only from verified facts, such as colour tone, opacity, transparency, gloss, matt, satin, speckled effect, reactive effect, depth, brightness, softness or variation after firing.
- Include firing information when supplied, such as cone range, firing temperature, earthenware suitability, stoneware suitability or kiln requirements. Never guess firing ranges.
- Add simple practical guidance where supported, such as applying even coats, testing before production work, using test tiles, allowing coats to dry or following manufacturer instructions.
- Use broad comparison language where useful, such as choosing fired colours when the maker wants kiln-fired decoration rather than a non-fired decorative finish, or choosing underglaze-style products when detailed painted decoration is needed before glazing.
- Add modest confidence points only where justified, such as usefulness for colour testing, building a fired colour palette or a supplied decorating workflow. Do not claim reliability, consistency, ease of use or professional results unless the evidence supports it.
- Explain product fit rather than making unsupported superiority claims. Avoid `better than`, `more durable than`, `easier than` or similar comparisons unless verified; instead explain when a maker would choose this product type for a particular workflow or finish.
- Keep ceramic product terminology accurate. Do not treat glaze, underglaze, stain, slip, fired colour and non-fired ceramic paint as interchangeable product types.
- Mention functional ware, tableware, food contact or dinnerware use only when the supplied safety, glaze and firing information supports that exact claim.
- Avoid generic creative filler such as `unleash your creativity`, `endless possibilities`, `perfect for every project`, `a must-have for any studio` or `suitable for beginners and professionals` unless there is a specific supported reason to say it.
- Do not infer the fired colour, finish or effect from packaging, an unfired liquid colour or a product name alone. Use supplied facts or a visible fired sample.
- Use natural internal links to related departments, ranges or support pages where relevant, such as ceramic glazes, underglazes, clear glazes, decorating products, firing accessories, MSDS/SDS pages or parent ranges. Keep this helpful and avoid over-linking.

### Fired colour paragraph guidance

A good fired colour snippet usually needs more than a flat product summary. It also should not be identical across a colour-heavy range. Aim for:

1. A purpose-led opening paragraph that names the product naturally and explains what the product helps the maker do. Keep the first sentence smooth and simple; do not make it carry every verified fact at once.
2. A second paragraph with supported application, firing, surface, decorating or buying context.
3. A short `<ul>` for practical use cases, handling notes or application guidance that does not duplicate the specification table.
4. Helpful buying-decision context where supplied, such as the project stage, whether a clear glaze is required, coat build-up, drying, surface preparation or firing sequence. Do not generalise manufacturer-specific instructions across unrelated ranges.
5. A product specification table when verified structured product facts are supplied.
6. One or two natural links where a useful parent range, related range, MSDS/SDS document or support page is supplied or can be safely identified.

### Fired colour copy examples

Avoid overloaded first sentences:

```text
Pink Ribbon Gare Surface Coat gives clean bisque a soft light pink fired background with a gloss surface, ready for ceramic decoration, pottery painting and painted bisque designs.
```

Better:

```text
Pink Ribbon Gare Surface Coat is a soft light pink gloss glaze for adding a fired background colour to clean bisque. It works well for pottery painting, decorative bisque pieces and designs that need a gentle pink base before firing.
```

Avoid dry copy:

```text
Sand Dune is a tan gloss glaze. Apply 3 coats and fire to Cone 06.
```

Better:

```text
Sand Dune Gare Surface Coat gives ceramic bisque a warm tan gloss background that can be decorated before firing. It is a useful choice for plates, ornaments and bisque shapes where you want a fired base colour without adding a separate clear glaze.
```

Avoid unsupported or overbuilt copy:

```text
Perfect for all pottery, professional ceramic production and food-safe tableware in every firing condition.
```

Better:

```text
Use it where the supplied firing and safety guidance matches the project, and test first when colour consistency matters across a batch.
```

## 7. Product HTML structure

- Product snippets should normally use the flexible product CMS structure.
- When verified structured facts are supplied, include a product specifications table using the purple Cromartie table styling from `cromartie_flexible_cms_styling_guidance_updated.md`.
- Use the table for clean facts such as product type, size, colour, finish, format, surface, application, firing, safety, compatibility or range only when supplied.
- Use the bullet list for practical guidance, uses, benefits or handling notes; do not repeat the exact same details in both the bullet list and specification table.
- Do not add ordinary paragraph/body text after the product specifications table. Treat the specification table as the final explanatory content section.
- Anything below the product specifications table should normally be limited to CTA buttons, simple inlink buttons or genuinely important customer notes only.
- If a link needs to appear after the specification table, use a simple standalone inlink box/CTA-style link only, not a loose sentence or paragraph such as `For more colours in this range...`.
- Two CTA buttons below the specification table are completely acceptable when two useful internal links are supplied, such as a parent range plus an MSDS/SDS document.
- Do not force internal links into paragraph text when CTA buttons below the table would be cleaner, clearer or more consistent with the snippet layout.
- Place natural inline text links before the specification table only when they improve the paragraph. After the specification table, use only CTA buttons/inlink boxes or important notes where needed.
- Minimum product snippet structure:
  - one `<h2>`
  - exactly two substantial `<p>` tags
  - one short `<ul>` only when it adds practical guidance without duplicating the paragraphs or table
  - one product specification table when verified structured facts are supplied
  - one or two relevant links/CTA buttons only where useful
- Do not include an `<h1>` inside the CMS HTML snippet.
- Use inline CSS only.
- Avoid unnecessary `<span>` tags.
- Use `<strong>` sparingly.
- Do not use italics unless they add genuine value.
- Put HTML in a normal fenced `html` code block when returning it in chat.

Recommended simple product structure:

```html
<div style="font-family: Open Sans, sans-serif; font-size:15px; line-height:1.7; color:#444;">

  <h2 style="color:#76689A; font-size:1.7em; font-weight:bold; margin-bottom:12px;">
    Purpose-led product heading here
  </h2>

  <p>First product paragraph with the product name mentioned naturally.</p>

  <p>Second product paragraph with helpful use, application or buying context.</p>

  <ul>
    <li>Useful product fact</li>
    <li>Useful product fact</li>
    <li>Useful product fact</li>
  </ul>

</div>
```

## 8. Product links and CTAs

- For CMS-ready product-page snippets, include at least one relevant internal link wherever a suitable range, parent department, support document, MSDS/SDS page or related product is available. Aim for two internal links when they are naturally useful and supported by the supplied page context.
- Product pages should usually have one or two links, not zero by default. Use zero links only when no relevant destination is supplied, no safe internal destination can be identified, or a link would be genuinely forced.
- Use links only where they help the customer move to a relevant range, accessory, compatible product, support page, safety document or parent department.
- Do not add large link panels or many range buttons to individual product descriptions.
- Do not repeat child-category links that already appear elsewhere in the CMS layout unless the page specifically needs a clear parent/range route.
- Every `<a>` tag must include a useful `title` attribute.
- Use natural anchor text. Do not force broad SEO keywords into link text.
- If the body copy names a specific related product, range, support page, MSDS/SDS document or parent department, an inline link can be used where it reads naturally, but it is not mandatory. A CTA button can be the cleaner choice.
- Two CTA buttons for internal links are acceptable, especially when the user supplies two required destinations or the page genuinely benefits from a range link plus a safety/support document link.
- Do not place normal paragraph text after a specification table just to add an internal link. If a post-table link is useful, format it as a simple standalone inlink box/CTA and keep the wording concise.
- Anything below the specification table should be restricted to CTA buttons/inlink buttons or important notes. Do not add extra explanatory body copy below the table.

## 9. Product image SEO rules

- Image title and alt text must describe what the image actually shows.
- Product image title text should read naturally and normally for the specific image. Do not force a fixed `[Colour] - [Range] [Type] [Size]` or other rigid format.
- The hyphenated `{colour} - {whatever else} {quantity}` pattern is not an image title or image alt text rule.
- Use the colour, brand/range, product type and size in image title text only where it helps accurately describe the image.
- For image alt text, lead with the colour first where possible for colour variants, but keep the wording readable, accurate and natural.
- The image title tag and image alt tag must not be exact duplicates. They can share the same core product facts, but should be naturally varied while staying accurate to the visible image.
- Use the image title tag as a concise product/image label, such as `[Colour] [Range] [Product Type] [Size] Jar Product Image`.
- Use the image alt tag to describe the visible image for accessibility, such as `[Colour] [range] [product type] [size] jar product image`.
- Do not create variation by adding unsupported claims. Both fields must remain accurate to the actual image.
- Do not claim a fired sample, brush-out, colour result, bottle, tub, tin, powder bag or group image unless it is visible.
- Do not invent finish, effect or fired colour from the product name alone.
- For packaging-only images, describe the product packaging, jar, bottle, tub or label rather than the fired result.
- For fired tile/sample images, describe the visible fired sample only and do not imply the packaging is shown.
- Include colour, range, product type and size where useful and visible/known.
- Keep image title and alt text readable and concise.
- Avoid keyword stuffing.
- Before finalising, compare `IMAGE_TITLE` and `IMAGE_ALT`: if they are identical, rewrite one of them so they are distinct without changing the facts.
